Harika, tasarım aşamasına başlamak projenin vizyonu için çok önemli. "Google ImageFX" (veya benzeri yapay zeka görsel araçları) genellikle İngilizce promptlarla (komutlarla) çok daha iyi ve tutarlı sonuçlar verir.

Senin için **"Risale-i Nur Takip Sistemi"**ne özel, modern, temiz ve İslami estetiği abartmadan modern UI (Kullanıcı Arayüzü) standartlarında birleştiren promptlar hazırladım.

Bu promptları araçlara yapıştırırken her seferinde aynı stili korumak için giriş kısımlarını (Style definition) sabit tuttum.

Genel Tasarım Dili (Style Guide)
Tüm promptlarda bu havayı kullanacağız:

Renk Paleti: Huzur veren Turkuaz/Petrol Yeşili (Teal), Beyaz, Altın Sarısı (Vurgular için) ve Gri tonları.

Tarz: Clean (Temiz), Minimalist, Flat Design, Soft Shadows (Yumuşak gölgeler), Rounded Corners (Yuvarlak köşeler).

Platform: Mobile Web App (iOS/Android hissiyatlı).

1. Ana Sayfa: "Okuduklarım" ve Kitap Listesi
Kullanıcının uygulamayı açtığında göreceği, kitapların listelendiği ekran.

Prompt:

High fidelity mobile app UI design, main dashboard screen for a book tracking application. Clean white background. A modern bottom navigation bar with icons for Home, Calendar, Friends, Profile. In the center, a vertical list of elegant cards. Each card represents a book with a minimal icon or book cover, titles like "Sözler", "Mektubat". Each card has a subtle 'Complete' button and a progress indicator. A floating action button (FAB) in teal color with a plus sign at the bottom right. Teal and gold color accents, soft drop shadows, modern sans-serif typography. 8k resolution, Figma style.

2. Veri Girişi: "Okuma Ekle" (Modal/Popup)
Kullanıcı bir kitaba tıkladığında açılan, "Bugün kaç sayfa okudun?" diye soran ekran.

Prompt:

High fidelity mobile app UI design, a popup modal overlay on top of a blurred background. The modal is white with rounded corners. Inside the modal, a clear question text "How many pages today?". A large, focused numeric input field showing the number "15". Below the input, a prominent primary button in teal color saying "Save Reading". A numeric keypad is visible at the bottom of the screen. Minimalist, clean, user-friendly interface.

3. Takvim ve İstatistik Ekranı
Kullanıcının geçmiş okumalarını gördüğü ekran.

Prompt:

High fidelity mobile app UI design, calendar and statistics screen. A clean monthly calendar view at the top. Days with reading activity have small teal circular badges or dots. Below the calendar, a summary section showing "Total Pages: 120". A list of daily logs below the summary, showing specific book titles and page counts for the selected date. Modern, data visualization style, soft colors, easy to read.

4. Arkadaş/Talebe Listesi (Medrese Takip)
Başkalarının ne okuduğunu görmek için kullanılan liste ekranı.

Prompt:

High fidelity mobile app UI design, social tracking screen. A list of users/friends. Each list item has a circular user avatar or initial, a user name like "Ahmet", "Mehmet", and a small status text showing "Last read: Today". A search bar at the top with rounded corners. An "Add Friend" button with an icon. Clean list layout, adequate whitespace, teal dividers.

5. Profil ve ID Paylaşım Ekranı
Kullanıcının kendi kodunu göreceği yer.

Prompt:

High fidelity mobile app UI design, user profile settings screen. At the top, a large circular placeholder for user photo. Below it, a prominent section displaying a unique 6-digit code "TR42X1" in large bold typography, designed like a copy-paste card. Below the code, a list of settings options like "Notifications", "Dark Mode", "Log Out". Minimal icons for each option. Clean, professional look.

6. Giriş (Login) Ekranı
Uygulamanın açılış ekranı.

Prompt:

High fidelity mobile app UI design, login screen. Minimalist background with a very subtle, faint Islamic geometric pattern overlay. In the center, a modern logo representing a book and light. Below the logo, a "Sign in with Google" button and an "Email Login" button. Clean, spacious, welcoming atmosphere. Teal branding colors..
